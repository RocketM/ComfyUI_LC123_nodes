# Skin reference for LC Skin Texture

`skin_reference_cc0.jpg` is the unmodified photograph **Image skin texture.jpg** (anonymous author, 13 March 2017),
a close-up of real human skin.

- Source: https://pixnio.com/textures-and-patterns/human-skin
- License record: https://commons.wikimedia.org/wiki/File:Image_skin_texture.jpg
- License: CC0 1.0 Universal (public domain).

LC Skin Texture takes only the fine brightness relief from it (pores, fine creases), never its colour or lighting.
Wire your own skin close-up into the node's `reference` input to use a different texture. The same photo ships with
ComfyUI-SkinDetailer, whose texture method this node is adapted from.
